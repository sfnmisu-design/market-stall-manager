Step 3
Open the SQL Editor
Left sidebar → look for the </> icon → SQL Editor → New query.
Step 4
Open supabase-schema.sql from your project folder
Right-click it → Open with → Notepad. Press Ctrl+A to select all, then Ctrl+C to copy.
Step 5
Paste and run
Click inside the SQL editor in Supabase → Ctrl+V to paste → click the green RUN button.
Done when: You see "Success. No rows returned" at the bottom.
Step 6 — Copy your API keys
Left sidebar → Settings → API

Deploy on Render

▼
Step 1
Open Render
Click the button below. Sign in with GitHub — it connects automatically.
🌐 Open render.com ↗
Step 2
Create a Static Site
Click New + → Static Site → Connect your GitHub account → find and select market-stall-manager.
Step 3 — Enter these exact settings
dashboard.render.com / new / static
Namemarket-stall-manager
Branchmain
Build Commandnpm install && npm run build
Publish Directorybuild
Publish Directory must be exactly: build — nothing else.
Step 4
Add Environment Variables
Scroll down → click Advanced → click Add Environment Variable twice:
Environment Variables
REACT_APP_SUPABASE_URLhttps://your-project.supabase.co
REACT_APP_SUPABASE_ANON_KEYeyJhbGci… (your key)
Paste your real values from Supabase — the ones you saved in Step A.
Step 5
Click "Create Static Site"
Watch the build log. After 2–3 minutes you'll see "Build successful" and a live URL appears at the top of the page.
Done when: You see a green Live badge and a URL like https://market-stall-manager.onrender.com — click it to open your app!
